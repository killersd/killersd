## 👨‍💻 Sobre mim

Atualmente, sou **Analista de Tecnologia da Informação no HU Brasil**, concursado, atuando em diferentes frentes da tecnologia, desde o desenvolvimento de aplicações até o gerenciamento de infraestrutura e segurança de ambientes corporativos.

Minha atuação combina desenvolvimento **Full Stack**, práticas de **DevOps**, administração de servidores, gerenciamento de redes e implementação de soluções voltadas à disponibilidade, segurança e eficiência dos serviços de TI.

- 💻 Desenvolvimento de aplicações web com Spring Boot, React e Angular.
- ⚙️ Conteinerização de aplicações com Docker e automação de pipelines CI/CD.
- 🗄️ Modelagem, utilização e administração de bancos de dados PostgreSQL.
- 🖥️ Administração e gerenciamento de infraestrutura de servidores e virtualização.
- 🌐 Gerenciamento de redes corporativas, equipamentos de rede e conectividade.
- 🔐 Segurança da informação, administração de firewalls e controle de tráfego de rede.
- 🚀 Interesse contínuo em automação, otimização de processos e evolução tecnológica.
